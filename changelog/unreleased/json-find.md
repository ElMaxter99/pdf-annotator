**Buscar en el JSON con Ctrl+F, como en VS Code (1.20.2, sin mesas por petición de Maxter):** con el foco en el editor de «Anotaciones (JSON)», `Ctrl/⌘ + F` abre arriba a la derecha el cuadro de búsqueda de VS Code: busca mientras escribes, «N de M», todas las coincidencias resaltadas y la actual marcada, `Intro` / `Mayús+Intro` (o ↑ ↓) para recorrerlas, `F3`, interruptores «Aa» (mayúsculas), «ab» (palabra completa) y «.*» (expresión regular) con `Alt+C/W/R`, borde rojo y «Sin resultados» si no hay ninguna, y `Esc` o ✕ para cerrar. Abrir con texto seleccionado lo busca. Colores de VS Code en oscuro y claro. Con pruebas unitarias del recuento y e2e.
