**«Personalizar» el JSON ahora es un modal (P-175 a P-177):** el desplegable pasa a ser una ventana centrada con las mismas opciones (claves, valores, sangría y coma final, con vista previa). Los cambios solo se guardan con «Aplicar»; Esc, ✕ y «Cancelar» lo cierran sin tocar nada. El mismo modal se usa junto a «Descargar JSON» del lote.
