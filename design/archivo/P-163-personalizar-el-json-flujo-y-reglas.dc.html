Personalizar el JSON del editor

En «Anotaciones (JSON)» un botón Personalizar abre el mismo formato que ya usan «Copiar JSON» y la descarga del lote: claves con o sin comillas, valores con comillas dobles o simples, sangría y coma final. El interruptor «Claves» de la mesa P-157 se sustituye por este botón; no hay un formato distinto para cada sitio.

Reglas

1

Una fila «Formato» bajo el título con dos píldoras que resumen lo elegido y el botón «Personalizar ▾». El menú es el de P-160, con el título «Personalizar el JSON».

2

El formato es único y se guarda una vez: lo que se ve en el textarea, lo que sale con «Copiar JSON», lo que baja «Descargar JSON» y lo que baja el lote. Por defecto: claves con comillas, valores con comillas dobles, sangría 2, sin coma final (JSON válido).

3

Al cambiar una opción, el texto del editor se reescribe una vez con el formato nuevo. No toca anotaciones ni historial. Con un error de sintaxis el botón queda desactivado: «Corrige el JSON para cambiar el formato».

4

La importación sigue leyendo cualquier formato, así que lo que se pega o se escribe se entiende igual.

5

Si el formato no es JSON estricto, el distintivo del panel lo dice. «Descargar JSON» baja ese formato (los archivos siguen llamándose .json) y el aviso lo repite.

6

Opciones › Editor muestra el mismo formato (claves y valores) y el botón «Restablecer», sincronizado. Teclado: Intro abre, Esc cierra, foco visible. 7 idiomas, ambos temas, solo escritorio.
