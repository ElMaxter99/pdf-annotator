Claves del JSON con o sin comillas

Hoy el editor «Anotación JSON» siempre escribe el texto con las claves entre comillas dobles y «Copiar JSON» entrega lo que haya escrito. Se añade un ajuste para elegir cómo se escriben las claves en el editor. Por defecto: con comillas (JSON válido).

Reglas

1

Un solo ajuste, «Claves del JSON»: Con comillas (por defecto) o Sin comillas (objeto JS).

2

Vive en dos sitios sincronizados: en el panel Anotación JSON y en Opciones › Editor. Cambiar uno cambia el otro.

3

Al cambiarlo, el texto del editor se reescribe una vez con el formato elegido. Las anotaciones no cambian y no entra nada en el historial.

4

Si el texto tiene un error de sintaxis, el interruptor queda desactivado con una pista: «Corrige el JSON para cambiar el formato».

5

Con «Sin comillas» el distintivo avisa «no es JSON estricto». La importación sigue leyendo ambos formatos.

6

«Copiar JSON» respeta el ajuste. Las opciones avanzadas de copia (comillas simples, sangría, coma final) siguen en el menú ▾.

7

Se recuerda por navegador y también en la app de escritorio. Los 7 idiomas, ambos temas, solo escritorio.
